# Virtual Assistant

This application would become a personal assistant for everyone that helps them to manage everything on their phone in a personalized way as they love, includes:
- Automatically track places where they visited to see where they love travelling mostly, then suggest visitting in the future.
- Full control to manage installed apps on their phone. The assistant can also know how much time apps already used, so it can stats and suggest them in a better way for using that app.
- Assistant can understand who they mostly contacts with and remind them to keep their good connections,...
- As a reminder.
